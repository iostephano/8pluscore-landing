Agentes de comercio de Anthropic

Anthropic publicó 8 agentes de comercio como código abierto.

4 atienden a los clientes dentro de una tienda online. 4 ayudan al equipo con ventas, inventario, precios y campañas.

Para usarlos necesitas Claude Code y una clave de la API de Claude con saldo. Cada mensaje consume crédito. El plan Pro no cubre este uso. Fuente oficial: github.com/anthropics/commerce-agents

Cómo usarlo

  1. Escribe la clave y descarga el repositorio. Descomprímelo.
  2. Abre la carpeta commerce-agents-main con Claude Code.
  3. Copia el prompt de abajo y completa el sector y la versión de tu agente.

Descarga

Se descarga desde el repositorio oficial en GitHub. Si no empieza, usa el botón.

El prompt

Esta carpeta es el repositorio commerce-agents de Anthropic. Quiero ejecutar la demo de [SECTOR] en su versión [VERSIÓN].
SECTOR puede ser retail, travel, entertainment o telecom.
VERSIÓN puede ser TIENDA, el agente de compras, o PANEL, el agente de comerciante.

1. Lee README.md y examples/[SECTOR]/README.md antes de hacer nada.
2. Revisa si tengo Python 3.11 o superior y Node 22. Si falta algo, dime cómo instalarlo en mi sistema y espera.
3. Crea el entorno virtual e instala las dependencias como dice el README.
4. Copia .env.example a .env. No me pidas la clave de la API en el chat. Dime que la pegue yo en el archivo .env y espera a que te confirme.
5. Ejecuta la demo con scripts/run_demo.py. Para PANEL usa la opción --merchant.
6. Cuando esté lista, dime qué dirección abrir en el navegador.
7. Dame en español los mensajes de prueba de la sección Try de ese sector, para que los copie en el chat de la demo.
No modifiques ningún archivo del repositorio, salvo el .env.

Qué esperar

  • Las empresas, productos y personas de las demos son ficticios. Los datos están en inglés y en dólares.
  • El agente no cobra ni hace pedidos reales. En el panel, todo cambio queda en borrador hasta que tú lo apruebes.
  • Es una implementación de referencia. Anthropic no le da soporte.
